# Veil of Ages

## Локальний запуск

1. Запусти `start-local.cmd` або команду `npm run local`.
2. Під час першого запуску система сама створить `.env.local` і відкриє його.
3. Скопіюй туди чинні значення `DATABASE_URL`, R2, OpenAI та YouTube з Render → Environment. Значення `YOUTUBE_SETUP_SECRET` має залишитися тим самим, бо ним зашифровано YouTube-доступ у Neon.
4. Запусти ще раз. Кабінет відкриється на `http://localhost:4000/factory`.

Локальний режим запускає кабінет, API і FFmpeg в одному вікні. Він доступний лише на цьому ПК, автоматично перевіряє NVIDIA NVENC і не потребує окремого `worker:local`.

Render поки не видаляємо: спочатку треба повністю перевірити локальне створення відео, Shorts і передачу на YouTube. Після цього Neon та R2 можна переносити окремими безпечними етапами.
